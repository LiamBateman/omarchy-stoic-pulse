# Changelog

## 1.1.0 - 2026-09-23

- Fix interval, pause/resume, and startup settings on current Omarchy's scoped
  plugin API, while retaining compatibility with older shell versions.
- Expand the offline rotation from 44 to 100 public-domain lines.
- Add 20 passages from Seneca's *Dialogues*, translated by Aubrey Stewart.
- Add 20 Epictetus passages and 16 Marcus Aurelius passages.
- Credit Aubrey Stewart for Seneca notifications instead of George Long.
- Restore four shortened quotations to full sentences and correct quotation marks.
- Verify all 100 passages and their locators against pinned source editions;
  label edition paragraph numbers accurately.
- Show notification errors in the popup and expose a diagnostic IPC status command.
- Add QML regression coverage for settings changes, pause/resume, manual delivery,
  and recurring notifications; document Do Not Disturb troubleshooting.

## 1.0.0 - 2026-08-24

- Initial release.
- Add a configurable recurring notification service.
- Add a theme-aware Omarchy bar popup with pause, send-now, and interval controls.
- Bundle a no-repeat rotation of public-domain Stoic lines for offline use.
